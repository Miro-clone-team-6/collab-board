# Code review

> **Статус:** 🚧 Черновик · 2026-11-11

Правила ревью для людей и для AI-ревьюеров. Общие правила проекта — в [AGENTS.md](../AGENTS.md).

## Что искать

Только то, что имеет реальный impact:

- баги и регрессии;
- безопасность: authn/authz, утечка данных (например, `passwordHash` в ответе), секреты в коде;
- нарушение контракта API: изменён ответ или параметры, а потребители не обновлены;
- целостность данных: несколько записей без транзакции, миграция без отката;
- race conditions и утечки ресурсов (подписки, сокеты, таймеры без cleanup);
- нарушения правил из `AGENTS.md`: FSD-импорты, `packages → apps`, проверки прав только в HTTP, но не в WebSocket-событиях.

## Чего не делать

- Не комментировать форматирование: это делает Biome.
- Не спорить о naming и вкусовщине.
- Не предлагать альтернативную реализацию, если текущая корректна.
- Не придумывать замечания ради количества. Если проблем нет, так и написать.

## Формат замечания

Что сломано → чем это грозит → как исправить (если решение очевидно).
Помечать серьёзность: **blocker** (нельзя мержить) или **nit** (можно поправить потом).
