# 📋 Стандарты разработки и качество бэкенда (`apps/api`)

Настоящий регламент определяет стандарты написания кода, обработки ошибок и тестирования серверной части CollabBoard.

---

## 1. Стандарты написания кода NestJS

1. **Единственная ответственность:** Контроллеры только принимают и отдают данные; вся логика содержится в сервисах.
2. **Внедрение зависимостей:** Все зависимости передаются через `constructor(private readonly ...)` с использованием Dependency Injection.
3. **Swagger-документация:** Каждый эндпоинт контроллера **ОБЯЗАН** содержать `@ApiTags()`, `@ApiOperation()`, `@ApiResponse()`. Без этого Orval не сможет сгенерировать хуки для фронтенда!
4. **Валидация через Zod:** Все входящие DTO валидируются схемами из `@packages/dto`.

---

## 2. Обработка ошибок и HTTP-статусы

Используйте стандартные исключения NestJS из `@nestjs/common`:

| Ситуация | Исключение | HTTP-код |
|---|---|---|
| Сущность не найдена по ID | `NotFoundException("Доска не найдена")` | 404 |
| Нарушение формата данных / валидации | `BadRequestException("Некорректные параметры")` | 400 |
| Пользователь не авторизован | `UnauthorizedException("Требуется вход в систему")` | 401 |
| Недостаточно прав для действия | `ForbiddenException("Нет доступа к этой доске")` | 403 |
| Конфликт уникальности (например, email уже занят) | `ConflictException("Email уже зарегистрирован")` | 409 |

---

## 3. Стандарты безопасности

* **Хэширование паролей:** Пароли хэшируются с помощью безопасных алгоритмов (Argon2id или bcrypt) перед записью в PostgreSQL.
* **Исключение секретов:** Запросы `prisma.user.findUnique` обязаны использовать `select`, исключающий поле `passwordHash`.
* **CORS и Cookies:** Cookies сессий передаются с флагами `HttpOnly; SameSite=Lax; Secure`.
