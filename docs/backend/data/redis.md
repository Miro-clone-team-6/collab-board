# ⚡ Redis: Кэширование, Сессии и Real-time Pub/Sub

> **Статус:** 🚧 На пересмотре — может описывать то, чего нет в коде. Источник правды — код и [architecture.md](../../architecture.md).

В проекте CollabBoard **Redis 7** используется в качестве высокопроизводительного in-memory хранилища.

---

## 1. Сценарии использования Redis

| Сценарий | Назначение | Формат ключа | TTL |
|---|---|---|---|
| **Сессии авторизации** | Хранение активных сессий пользователей и токенов | `auth:session:{sessionId}` | Срок действия refresh токена (7d) |
| **Ограничение частоты (Rate Limiting)** | Защита от перебора паролей и спам-запросов | `rate_limit:{ip}:{action}` | 60 секунд |
| **Real-time Pub/Sub (WebSockets)** | Синхронизация перемещений курсоров и фигур между несколькими инстансами сервера | Redis Pub/Sub канал: `board:{boardId}:events` | Мгновенно |
| **Присутствие на доске (Presence)** | Список пользователей, которые прямо сейчас открыли доску | Redis Set: `board:{boardId}:active_users` | С продлением через ping (Heartbeat) |

---

## 2. Pub/Sub архитектура для масштабирования сокетов

Когда к интерактивной доске подключены десятки участников, сервер должен рассылать координаты курсоров и изменения фигур в реальном времени.

Если в будущем запускается несколько инстансов бэкенда за балансировщиком нагрузки (Nginx/Traefik), клиент А может быть подключен к Серверу 1, а клиент Б — к Серверу 2.  
**Redis Pub/Sub** выступает связующей шиной (Socket.io Redis Adapter), мгновенно передавая события холста между нодами бэкенда:

```text
Пользователь А (передвинул стикер)
       │
       ▼
   Сервер 1 ──► [Redis Channel: board:123:events]
                       │
                       ▼
                   Сервер 2
                       │
                       ▼
              Пользователь Б (видит изменение)
```

## 3. Запуск и конфигурация

Контейнер Redis поднимается автоматически через Docker Compose:
```bash
pnpm infra:up
```
Строка подключения берется из переменной окружения `REDIS_URL`:
```env
REDIS_URL=redis://:redis_password@localhost:6379
```
