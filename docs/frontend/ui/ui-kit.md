# 🧩 UI Kit & Дизайн-система (@packages/ui)

> **Статус:** 🚧 На пересмотре — может описывать то, чего нет в коде. Источник правды — код и [architecture.md](../../architecture.md).

Пакет `packages/ui` (`@packages/ui`) содержит презентационные базовые компоненты дизайн-системы монорепозитория.

---

## 1. Базовые принципы UI Kit

* **Примитивы:** Построены на базе **Radix UI** (доступность из коробки WAI-ARIA, фокус, клавиатурная навигация).
* **Стили:** Стилизуются через **Tailwind CSS** и утилиту `cn()` из `@packages/shared`.
* **Чистота:** Компоненты UI Kit **НЕ имеют бизнес-логики**, не знают о досках (`board`), пользователях (`user`) или API.

---

## 2. 🌲 Дерево решений: «Мне нужен новый UI-компонент»

```text
Нужен компонент (например, Button, Modal, Dropdown, Slider)?
│
├── 1. Есть ли компонент в @packages/ui?
│   └── ДА ──► Импортируем: import { Button } from "@packages/ui"
│
├── 2. Компонент общий и нужен в нескольких приложениях/экранах?
│   └── ДА ──► Создаем в packages/ui/src/
│              └── Экспортируем в packages/ui/src/index.ts
│
└── 3. Компонент специфичен ТОЛЬКО для конкретного экрана/слайса доски?
    └── ДА ──► Создаем в apps/web/src/shared/ui/ или внутри слайса фичи
```

## 3. Ленивая загрузка тяжелых компонентов (`next/dynamic`)

Для минимизации размера начального JavaScript-бандла (Initial Bundle Size):
* **Модальные окна (`Dialog`) и шторки (`Drawer`):** открываются пользователем по клику и не нужны на этапе первой загрузки страницы. Загружайте их лениво через `next/dynamic`.
* **Экспорт доски в PNG/PDF (html2canvas, jsPDF):** библиотеки экспорта очень тяжелые, их загрузка должна производиться только в момент клика на кнопку «Экспорт».
* **Базовые атомарные элементы (`Button`, `Input`, `Badge`):** рендерятся сразу, их оборачивать в `dynamic` не нужно.
