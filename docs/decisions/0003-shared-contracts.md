# 0002. Общие HTTP-контракты на Zod

> Статус: ✅ Принято, реализовано для healthcheck.
> Дата: 2026-11-11.
> Заменяет [ADR 0001](0001-api-contracts.md).

## Контекст

Фронтенду и API нужны одинаковые типы HTTP-данных и runtime-проверка JSON.
Разработка фронтенда не должна требовать работающего API или импорта его кода.

## Решение

Источник HTTP-схем — `packages/contracts`. Типы выводятся из Zod;
Nest DTO и Swagger используют эти же схемы через `nestjs-zod`.
Пакет не зависит от Nest, Prisma и React.

Клиент из OpenAPI не генерируется. Prisma-модели остаются внутри API.
Подключение к Nest описано в [backend](../backend/README.md#http-контракты).

## Последствия

Фронтенд может работать с моками по согласованной схеме, пока API реализует
эндпоинт. Метод, путь и HTTP-статусы согласуются отдельно: Zod их не проверяет.
Для независимых релизов изменения контракта должны сохранять совместимость;
удаление полей и добавление обязательных полей требуют согласованного перехода.
