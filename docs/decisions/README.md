# Решения (ADR)

> 🚧 Черновик

Здесь записываются архитектурные решения: **что** решили, **почему** и **что отбросили**.
Документ описывает решение, а не обязательно существующий код: смотри статус.

## Статусы

| Статус                     | Значение                                                        |
| -------------------------- | --------------------------------------------------------------- |
| 💬 Обсуждается             | Решение не принято, есть открытые вопросы                       |
| 📐 Принято, не реализовано | Договорились, кода ещё нет. Не ссылаться как на существующее    |
| ✅ Принято, реализовано    | Решение действует, код соответствует                            |
| ⏸ Отложено                 | Подход описан и может пригодиться, но сейчас не используется    |
| ⛔ Отклонено               | Рассмотрели и отказались (сохраняем, чтобы не обсуждать заново) |
| ♻️ Заменено                | Заменено другим ADR, ссылка на него                             |

## Как добавить

1. Скопировать шаблон ниже в `NNNN-короткое-имя.md` (следующий номер).
2. Добавить строку в таблицу выше.
3. Обсудить в PR. Когда решение реализовано — обновить статус.

Номера не переиспользуются. Отменённое решение не удаляется, а получает статус ⛔ или ♻️.

## Шаблон

```markdown
# NNNN. Название

- **Статус:** 💬 Обсуждается
- **Дата:** YYYY-MM-DD
- **Issue:** #123

## Контекст

Какая проблема, какие ограничения.

## Решение

Что делаем. Конкретно.

## Альтернативы

Что рассматривали и почему не выбрали.

## Последствия

Что становится проще, что сложнее, что нужно сделать.
```
