# Решения

| ADR | Решение | Статус |
| --- | --- | --- |
| [0001](0001-api-contracts.md) | Генерация клиента из OpenAPI | Заменено ADR 0002 |
| [0002](0002-shared-contracts.md) | Общие HTTP-контракты на Zod | Принято, реализовано для health |
| [0003](0003-backend-modules.md) | Плоские модули backend | Принято, текущий пример — health |

ADR содержит контекст, решение, рассмотренные альтернативы и последствия.
Инструкции и устройство кода находятся в разделах соответствующих частей системы.

Принятое решение добавляется файлом `NNNN-короткое-имя.md` и строкой в таблицу.
`NNNN` — номер соответствующей задачи в трекере.
В начале указываются статус и дата. Статус принятия и наличие реализации
указываются отдельно: принятие решения само по себе не означает готовый код.
Заменённый ADR сохраняется со ссылкой на новое решение. Номера не переиспользуются.
