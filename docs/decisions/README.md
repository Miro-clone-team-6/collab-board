ADR содержит контекст, решение, рассмотренные альтернативы и последствия.
Инструкции и устройство кода находятся в разделах соответствующих частей системы.

## Статусы

| Значок | Статус | Значение |
| --- | --- | --- |
| 💬 | Предложено | Обсуждается, ещё не принято |
| ✅ | Принято | Решение действует |
| ❌ | Отклонено | Рассмотрено и не принято |
| 🗄️ | Устарело | Больше не действует, замены нет |
| ♻️ | Заменено | Действует другой ADR, ссылка в статусе |

## Добавить ADR

1. Скопировать [шаблон](../_templates/adr.md) в `decisions/NNNN-short-name.md`.
   `NNNN` — номер issue, `short-name` — латиницей через дефис. Из одной issue может
   вырасти несколько решений, поэтому номер повторяется, а различает их `short-name`.
2. Заполнить статус, состояние реализации, дату и ссылку на issue. Статус принятия
   и наличие реализации указываются отдельно: принятое решение не означает готовый код.
3. Добавить строку в таблицу выше.

ADR ссылаются друг на друга по имени файла: одного номера недостаточно.
Принятый ADR не переписывается. Новое решение оформляется новым ADR, а у старого
статус меняется на «Заменено» со ссылкой на новый.
